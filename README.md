# slopkit installer

PS5 installer payload for [slopkit][slopkit].

## Installing
Assuming you have [elfldr.elf][elfldr] running on your PS5, the launcher
can be installed by running [the install payload][install] on your PS5.
A slopkit icon will then appear on the Media tab on your PS5 dashboard.

> [!NOTE]
> Once the installation is completed, the application can be launched without
> having to jailbreak the console after a reboot.
